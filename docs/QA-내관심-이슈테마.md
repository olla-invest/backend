## ⚪ 1·2 — 이슈테마와 실시간차트의 기준 시점이 다르다 (사양)

### 재현 (dev, 2026-09-30)

이슈테마 `100177` 상세의 3종목 중 **GS만 실시간차트에 없다.**

| 종목 | 마감 종가 | MA50 | 여유 | 차트 노출 |
|---|---|---|---|---|
| GS (078930) | 108,700 | 107,786 | **+0.85%** | ❌ |
| S-Oil (010950) | 157,800 | 144,724 | +9.0% | ✅ |
| SK이노베이션 (096770) | 145,900 | 127,978 | +14.0% | ✅ |

### 원인

- **이슈테마**: 마감 확정 스냅샷(`theme_daily_snapshots` ← `stock_current_rank_snapshots`) 기준
- **실시간차트**: 조회 시점 실시간가로 동적 필터(DF1~DF3)를 **다시 평가**

GS는 마감 시점에 `DF3: 현재가 > MA50` 을 0.85% 차이로 통과했다. 장중 실시간가가 MA50 아래로
내려가면 그 순간 차트에서 빠진다. **경계선 종목은 장중에 들락날락하는 것이 정상 동작이다.**

버그가 아니라 두 화면의 평가 시점이 다른 데서 오는 필연적 결과다.

### 남은 과제

상세 화면의 안내문 `이슈 테마에 포함된 종목은 실시간 차트에서 조회되는 종목에 한해 제공됩니다`
가 이 상황을 설명하지 못한다. 사용자는 "있다는데 왜 없냐"로 읽는다. 문구 보완이나
마감 기준임을 명시하는 표기가 필요하다. (기획 판단)

## 🔵 17 — 프론트가 `rank` 대신 행 번호를 그린다

### 검증 (dev, 2026-09-30)

```
전체 목록:  rank=3  웹툰
검색 후:    rank=3  웹툰    ← 순위 유지됨
```

API 는 저장된 `snapshot.rank` 를 그대로 내보내고, 검색은 그 뒤에 배열 필터만 건다
(`issue-theme.service.ts:263`). **백엔드는 정상이다.**

QA 스크린샷에서 "RS순" 정렬인데도 순위가 1·2·3·4 로 연속인 것이 결정적 근거다.
`rank` 를 쓴다면 RS순 정렬에서는 순위가 띄엄띄엄 나와야 한다.

**조치**: 순위 칸을 행 인덱스가 아니라 `item.rank` 로 렌더. 프론트 수정 사항.

## ⚪ 3 — 종가는 우리 값이 맞다

| 종목 | 우리 DB | 키움 원주가 | 키움 수정주가 | 토스 |
|---|---|---|---|---|
| 케이아이엔엑스 | 149,300 | 149,300 | 149,300 | 150,300 |
| 씨젠 | 30,750 | 30,750 | 30,750 | 30,600 |
| 슈프리마 | 63,700 | 63,700 | 63,700 | 64,000 |

키움의 원주가·수정주가가 동일하고 우리 DB도 일치한다. 수정주가 적용 차이도, 백필 누락도 아니다.

토스 값은 방향이 제각각(+1,000 / −150 / +300)이라 시점 차이로 보기 어렵고,
**넥스트장(시간외) 반영분**일 가능성이 높다. 키움 `ka10081` 일봉은 정규장 종가만 담는다.

버그는 아니나, 사용자가 나란히 비교할 때 다른 값을 보는 건 사실이므로
기준 명시("정규장 종가")나 넥스트장 반영 여부는 기획 판단.

## ✅ 5·7·9·16 — `20260831` 마이그레이션으로 해소

QA 시점(8/10) 이후 `20260831_source_themes_from_stock_snapshots` 로 테마 집계가
`stock_current_rank_snapshots` 파생 방식으로 바뀌면서 함께 해결됐다.

`GET /watchlist/themes` (dev, 2026-09-30):

```json
{ "themeCode": 100104, "rank": 1, "prevRank": 1,
  "risingCount": 0, "totalCount": 1,
  "upCount": 0, "flatCount": 0, "downCount": 1, "event": "-" }
```

16번(모수 불일치)도 현재는 일치한다. 테마 `100177` 기준 스냅샷 `total=3, down=3` 이고
상세 API 도 종목 3개(GS −4.90%, S-Oil −3.78%, SK이노베이션 −8.18%)를 반환한다.

> 참고: 테마는 이미 백엔드가 완성된 문구를 `event` 필드로 내려준다
> (`테마 순위가 4 → 1으로 상승했어요.(+3)` / 변동 없으면 `-`). 기획서의 표기 규칙이
> 그대로 구현돼 있다. **종목은 `events: ['RANK_UP', ...]` 코드 배열만 주고 문구 조립을
> 프론트가 한다** — 종목 카드에서만 NaN 이 났던 이유다. 종목도 테마처럼 문구를
> 내려주면 표기 규칙이 한 곳에 모인다.
