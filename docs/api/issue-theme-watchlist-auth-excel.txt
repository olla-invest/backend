1. 로그인 관련 API  /auth
인증 방식: 앱 전체 JwtAuthGuard 전역 적용  /  🔒 표시 엔드포인트만 토큰 필요  /  JWT 만료: 7일


1-1. 회원가입
POST /auth/register

파라미터 (Body · application/json)
파라미터명	타입	필수 여부	제약 / 설명
username	String	필수	4~20자, 영문·숫자만  (/^[a-zA-Z0-9]{4,20}$/)
password	String	필수	8~50자
email	String	필수	이메일 형식, 최대 100자
name	String	필수	최대 100자
phone	String	필수	최대 20자
agreeService	Boolean	필수	true 이어야 가입 가능 (false 시 400 에러)
agreePrivacy	Boolean	필수	true 이어야 가입 가능 (false 시 400 에러)
agreeMarketing	Boolean	선택	마케팅 수신 동의, 기본값 false

호출 예시
POST /auth/register
Content-Type: application/json

{
  "username": "honggildong",
  "password": "myPass123!",
  "email": "hong@example.com",
  "name": "홍길동",
  "phone": "010-1234-5678",
  "agreeService": true,
  "agreePrivacy": true,
  "agreeMarketing": false
}

Response 201
{
  "userId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "username": "honggildong",
  "email": "hong@example.com",
  "name": "홍길동"
}

에러
상태코드	메시지	발생 조건
400	필수 약관에 동의해주세요	agreeService 또는 agreePrivacy 가 false
409	이미 사용 중인 ID입니다	동일 username 계정 존재
409	이미 사용 중인 이메일입니다	동일 email 계정 존재


1-2. 로그인
POST /auth/login

파라미터 (Body · application/json)
파라미터명	타입	필수 여부	제약 / 설명
username	String	필수	로그인 아이디
password	String	필수	비밀번호

호출 예시
POST /auth/login
Content-Type: application/json

{
  "username": "honggildong",
  "password": "myPass123!"
}

Response 200
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "userId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "username": "honggildong",
    "email": "hong@example.com",
    "name": "홍길동",
    "isTempPassword": false
  }
}

필드 설명 (Response)
필드명	타입	설명
accessToken	String	JWT 토큰 (7일 유효)  —  이후 요청 시 Authorization 헤더에 포함
user.isTempPassword	Boolean	임시 비밀번호 여부  —  true: 비밀번호 찾기로 발급된 임시 비밀번호 상태 → 로그인 후 비밀번호 변경 화면으로 강제 이동 필요

에러
상태코드	메시지	발생 조건
404	가입된 계정이 없습니다. 회원가입 후 이용해주세요.	username 일치 계정 없음
401	비밀번호가 일치하지 않습니다.	비밀번호 불일치


1-3. 아이디 찾기
POST /auth/find-id

파라미터 (Body · application/json)
파라미터명	타입	필수 여부	제약 / 설명
name	String	필수	가입 시 입력한 이름
email	String	필수	가입 이메일

호출 예시
POST /auth/find-id
Content-Type: application/json

{
  "name": "홍길동",
  "email": "hong@example.com"
}

Response 200
{
  "maskedUsername": "hong****g"
}

필드 설명 (Response)
필드명	타입	설명
maskedUsername	String	마스킹된 아이디  —  5자 이상: 앞 4자 + 중간 * + 마지막 1자  (예: honggildong → hong******g)  /  4자 이하: 앞 2자 + * 처리 (예: ab12 → ab**)

에러
상태코드	메시지	발생 조건
404	사용자 정보가 일치하지 않습니다	name + email 일치 계정 없음


1-4. 비밀번호 찾기 (임시 비밀번호 이메일 발송)
POST /auth/find-password

파라미터 (Body · application/json)
파라미터명	타입	필수 여부	제약 / 설명
username	String	필수	로그인 아이디
email	String	필수	가입 이메일

호출 예시
POST /auth/find-password
Content-Type: application/json

{
  "username": "honggildong",
  "email": "hong@example.com"
}

Response 200
{
  "email": "hong@example.com"
}

처리 흐름
1. username + email 일치 계정 조회
2. 12자리 임시 비밀번호 생성  (대문자 2 + 소문자 2 + 숫자 2 + 특수문자 2 + 랜덤 4, 셔플)
3. 임시 비밀번호 bcrypt 해시 후 DB 저장
4. isTempPassword = true 로 업데이트
5. 가입 이메일로 임시 비밀번호 발송  →  로그인 후 비밀번호 변경(1-5) 필수

에러
상태코드	메시지	발생 조건
404	입력하신 정보로 가입된 계정을 찾을 수 없습니다. 다시 확인해주세요.	username + email 일치 계정 없음


1-5. 비밀번호 변경  🔒
PATCH /auth/change-password

파라미터 (Header)
파라미터명	타입	필수 여부	설명
Authorization	String	필수	Bearer <accessToken>

파라미터 (Body · application/json)
파라미터명	타입	필수 여부	제약 / 설명
newPassword	String	필수	새 비밀번호, 8~50자
confirmPassword	String	필수	새 비밀번호 확인  —  newPassword 와 동일해야 함

호출 예시
PATCH /auth/change-password
Content-Type: application/json
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

{
  "newPassword": "newSecurePass1!",
  "confirmPassword": "newSecurePass1!"
}

Response 200
{
  "message": "비밀번호가 변경되었습니다."
}

비고
성공 시 isTempPassword = false 로 초기화
임시 비밀번호 로그인 상태(isTempPassword=true)에서 이 API 호출 후 정상 이용 가능

에러
상태코드	메시지	발생 조건
400	비밀번호가 일치하지 않습니다.	newPassword ≠ confirmPassword
401	Unauthorized	토큰 없음 또는 만료



2. 이슈테마 API  /issue-theme
인증: 불필요 (전체 공개)

종목 집계 기준: 정적 필터(passedStaticFilters=true) 통과 종목 중 아래 동적 필터 3가지를 모두 통과한 종목만 사용
DF1	현재가 ≥ 52주 저가 × 1.3
DF2	현재가 ≥ 52주 고가 × 0.75
DF3	현재가 > 50일 이동평균

2-3. 관리용 엔드포인트 (수동 호출)
스케줄러가 자동 실행하며, 필요 시 수동으로 직접 호출하는 관리용 엔드포인트

POST /issue-theme/sync-themes
설명	키움 API 종목 리스트의 upName → themes 테이블 + company.themeCode 동기화 (최초 1회)
호출 예시	POST /issue-theme/sync-themes
Response 201	{ "themesCreated": 3, "companiesUpdated": 142 }

POST /issue-theme/snapshot/theme
설명	테마 일별 스냅샷 저장  —  장 마감 후 1회 호출 (스케줄러: 평일 15:40 KST)
호출 예시	POST /issue-theme/snapshot/theme
Response 201	{ "saved": 19, "date": "2026-03-20" }

POST /issue-theme/snapshot/trading-value
설명	실시간 누적 거래대금 스냅샷 저장  —  장중 10분 단위 호출 (스케줄러: 09:00~15:30, 매 10분)
호출 예시	POST /issue-theme/snapshot/trading-value
Response 201	{ "saved": 312, "time": "1030" }

prevRank	Number | null	전일 RS 순위  —  null이면 RANK_UP/RANK_DOWN 이벤트 미발생
relativeStrengthScore	Number | null	RS 점수
isNewHigh	Boolean	신고가 여부
events	String[]	이벤트 목록  —  해당 없으면 빈 배열 []

이벤트 종류
이벤트	발생 조건
NEW_HIGH	당일 신고가 달성 (isNewHigh = true)
RANK_UP	전일 대비 순위 상승 (rank < prevRank)
RANK_DOWN	전일 대비 순위 하락 (rank > prevRank)

비고
응답 정렬: addedDate 내림차순  (최근 추가 종목이 맨 앞)
지표 데이터(rank, closePrice 등)는 최신 거래일 DB 기준

에러
상태코드	메시지	발생 조건
401	Unauthorized	토큰 없음 또는 만료

POST /watchlist/stocks

파라미터 (Header)

파라미터명	타입	필수 여부	제약 / 설명
stockCode	String	필수	종목 코드 (6자리,  예: "005930")

호출 예시
POST /watchlist/stocks
Content-Type: application/json

}

Response 201

  "userId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",

  "addedDate": "2026-03-20T09:15:00.000Z",
  "deletedAt": null,
  "memo": null,
  "company": {
    "stockCode": "005930",
    "companyName": "삼성전자",

필드 설명 (Response)
필드명	타입	설명

3-3. 관심종목 삭제
DELETE /watchlist/stocks/:stockCode

파라미터 (Header)
파라미터명	타입	필수 여부	설명
Authorization	String	필수	Bearer <accessToken>

파라미터 (Path)
파라미터명	타입	필수 여부	설명
stockCode	String	필수	삭제할 종목 코드 (6자리)

호출 예시
DELETE /watchlist/stocks/005930
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Response 200

  "message": "관심종목에서 삭제되었습니다",

}
